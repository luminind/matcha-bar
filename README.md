# Matcha Bar — site vitrine

Site statique, sans dépendance ni envoi de formulaire configuré pour le moment.

## Lancer en local

Depuis ce dossier, lancer un serveur statique :

```sh
python3 -m http.server 4173
```

Puis ouvrir <http://localhost:4173> dans un navigateur.

Le formulaire est une maquette visuelle : le bouton affiche un message de démonstration et n’envoie ni ne stocke aucune donnée. Les images du site sont des versions optimisées des photos conservées dans `PHOTOS/`.
